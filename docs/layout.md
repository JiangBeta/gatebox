# GateBox · 页面布局设计

> 状态：PRD v2（2026-09）—— 一级导航扩为 6 入口，「Docker」改名「容器」，域名页新增 DDNS，新增网络模块
> 关联：`docs/PRD.md` §8

## 1. 布局总览

```
┌────────┬──────────────────────────────────────────┐
│  LOGO  │ 页面标题               ┌──────┐ ┌──────┐ │
├────────┼────────────────────────┘ Tab1 └─┴──────┴─┤
│ 首页   │                                          │
│ 网关   │                                          │
│ 容器   │                                          │
│ 域名   │               主要页面区                 │
│ 网络   │                                          │
│ 设置   │                                          │
│        │                                          │
│ Github │                                          │
│ 文档   │                                          │
│ 🌐 🌓  │                                          │
│ 退出   │                                          │
└────────┴──────────────────────────────────────────┘
```

## 2. 一级导航（左侧，顶级入口）

- 六个顶级入口：**首页 / 网关 / 容器 / 域名 / 网络 / 设置**（「Docker」更名「容器」，PRD v2）。
- 侧边栏底部（退出上方，小字）：**Github 链接 / 文档链接 / 🌐 语言切换 / 🌓 主题（深/浅/auto）**。
- 侧边栏最底部：**退出**。

## 3. 二级导航（右上 Tab）

- 每页右上以 Tab 区隔。
- 首页 Tab：导航 / 仪表盘（导航内嵌 flame）。
- 网关页 Tab：代理 / Caddy 片段。
- 容器页 Tab：概览 / 编排 / 镜像 / 网络 / 存储卷。
- 域名页 Tab：概览 / 域名 / 证书 / **DDNS**（新增）。
- 网络页 Tab：内网 DNS（mosdns）/ 组网（Tailscale）。
- **设置页 Tab：常规 / 变量**（变量为网关与容器的统一管理入口，ADR-035）。

## 4. 三级操作（button + 弹出层）

- 三级操作以 button 放置于右上 Tab 下侧，点击弹出层操作。
- **弹出层规范**：表单 / 详情 / 编辑器类弹出层一律用 **Drawer**，从右向左滑出（`placement="right"`）；确认类对话框（删除 / 接管等「是 / 否」）用 **Modal**。

## 5. 顶部

- LOGO + 页面标题 + 二级 Tab。
- 版本号：LOGO 右侧小字灰色，有更新时弹红色 NEW Badge。

## 6. 底部区域（决策：去掉）

去掉 footer。理由：

1. 垂直可视范围最大化（HomeLab 常小屏访问，高度稀缺）；
2. 自托管无需 ICP/备案，footer 无必须承载的法律信息；
3. 官网 / 文档 / 版本信息已有归属（官网文档 → 侧边栏小字，版本号 → LOGO 右侧，细粒度「关于」→ 设置页）。
