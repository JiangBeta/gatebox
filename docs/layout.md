# GateBox · 页面布局设计

> 状态：设计已定，待开发
> 关联：`CLAUDE.md`（页面布局章节）、`docs/domain.md`（域名页 4 Tab）

## 1. 布局总览

```
┌────────┬──────────────────────────────────────────┐
│  LOGO  │ 页面标题               ┌──────┐ ┌──────┐ │
├────────┼────────────────────────┘ Tab1 └─┴──────┴─┤
│ 仪表盘 │                                          │
│ 网关   │                                          │
│ Docker │                                          │
│ 域名   │               主要页面区                 │
│ 设置   │                                          │
│        │                                          │
│ Github │                                          │
│ 文档   │                                          │
│ 🌐 🌓  │                                          │
│ 退出   │                                          │
└────────┴──────────────────────────────────────────┘
```

## 2. 一级导航（左侧，顶级入口）

- 五个顶级入口：**仪表盘 / 网关 / Docker / 域名 / 设置**。
- 侧边栏底部（退出上方，小字）：**Github 链接 / 文档链接 / 🌐 语言切换 / 🌓 主题（深/浅/auto）**。
- 侧边栏最底部：**退出**。

## 3. 二级导航（右上 Tab）

- 每页右上以 Tab 区隔。
- 网关页 Tab：代理应用列表 / 代理规则维护 / caddy 控制。
- 域名页 Tab：概览 / 域名管理 / SSL 证书 / DNS 凭证（见 `docs/domain.md`）。

## 4. 三级操作（button + 弹出层）

- 三级操作以 button 放置于右上 Tab 下侧，点击弹出层操作。

## 5. 顶部

- LOGO + 页面标题 + 二级 Tab。
- 版本号：LOGO 右侧小字灰色，有更新时弹红色 NEW Badge。

## 6. 底部区域（决策：去掉）

去掉 footer。理由：

1. 垂直可视范围最大化（HomeLab 常小屏访问，高度稀缺）；
2. 自托管无需 ICP/备案，footer 无必须承载的法律信息；
3. 官网 / 文档 / 版本信息已有归属（官网文档 → 侧边栏小字，版本号 → LOGO 右侧，细粒度「关于」→ 设置页）。

## 7. 术语统一

- 「网关」承载所有被代理的应用；一级导航统一为「网关」（PRD 原「应用」已改）。
