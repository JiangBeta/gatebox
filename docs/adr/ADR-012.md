# ADR-012：域名领域模型

- 状态：已接受
- 日期：2026-08-21

## 背景

域名功能（Domain）是控制面四大核心能力之一。需明确 Domain 的管理单位、二级域名的来源，以及解析与证书的粒度，才能落地数据模型与页面。

## 决策

1. **Domain = rootDomain**（如 `neob.cn`），是域名管理的独立实体、基本单位；apex 根域名也是合法 Domain。
2. **二级域名不建实体**：由网关页 ProxyRoute 的 host 产生（「没有目的地的域名没有意义」），域名页只统计其数量。
3. **凭证关联**：Domain 通过 `credential_id` 引用 `DNSCredential`（ADR-003）；多个 Domain 可共享同一凭证。
4. **解析方式**：仅走 ddnsgo 自动上报（ADR-004），**按二级域名逐条上报 A 记录**；固定公网 IP 也由 ddnsgo 以「固定 IP」方式上报。
5. **多主机（后置）**：本期单实例单主机；「单一控制面管理多台主机」为后续方向，数据模型与接口预留扩展点。

## 后果

- 优点：管理单位清晰（rootDomain）；二级域名随路由自然增减，无孤儿域名。
- 约束：二级域名数量由网关页路由聚合得出；删除 Domain 需校验其下无路由引用。
