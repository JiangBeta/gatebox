# ADR-006：证书 challenge 方式

- 状态：已接受
- 日期：2026-08-20

## 背景

域名证书自动化由 Caddy ACME 承担。国内家庭宽带 80/443 端口常被运营商封锁，HTTP-01 不可靠。

## 决策

**DNS-01 为默认**（HTTP-01 可选回退）。预装 caddy DNS 插件：**cloudflare、dnspod.cn、aliyun**（注意是 **dnspod.cn** 国内版，非 dnspod.com 国际版）。

证书签发范围：**仅被代理域名**（代理即签证），无独立证书管理。

## 后果

- 优点：不受 80/443 封锁影响，支持通配符证书。
- 约束：分发包需带 `xcaddy` 预构建、含上述 DNS 插件的 caddy 二进制；需管理各提供商 API key（见 ADR-003）。
