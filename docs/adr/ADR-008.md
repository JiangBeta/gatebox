# ADR-008：统一 App 领域模型

- 状态：已接受
- 日期：2026-08-20

## 背景

「docker 自动代理」和「手动代理」若分开建模会形成两套心智。

## 决策

**统一 App 模型**：App 是核心实体，`source ∈ {docker, manual, host}` 区分来源；ProxyRoute 挂在 App 下，一 App 多规则。

手动代理后端为**仅 IP:端口**（可多个 = caddy 多 upstream 负载均衡），命名由 App 的 `name` 承担。

代理类型（一期）：`reverse_proxy`（后端 http/https）+ `file_server`（静态网页）+ `tcp_stream`（L4）。

## 后果

- 优点：UI 与数据模型统一，一套心智。
- 约束：模型需覆盖三种 source 与三种 route 类型的组合。
