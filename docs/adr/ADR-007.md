# ADR-007：Docker label 约定

- 状态：已接受
- 日期：2026-08-20

## 背景

「docker 基于 label 的自动代理」需要一套 label 命名约定。

## 决策

**复用 `caddy.*` 约定**（`caddy`、`caddy.reverse_proxy`、`caddy.tls`、`caddy_0`/`caddy_1`…），另留 **`gatebox.*` 扩展命名空间**放本工具特有元数据。

参考 caddy-docker-proxy：`caddy: domain`、`caddy.reverse_proxy: "{{upstreams 80}}"`、`caddy.tls.dns: "cloudflare {env.TOKEN}"`。

## 后果

- 优点：兼容 caddy-docker-proxy 生态，已有容器零改动迁移。
- 约束：需实现「读 Docker label → 生成 App/ProxyRoute」的映射。

> **2026-08-25 命名统一**：扩展前缀由 `appgateway.*` 改为 `gatebox.*`（项目更名，见 `docs/docker.md` §10）。
> **补充**：GateBox 自行生成 Caddyfile、**不安装 caddy-docker-proxy 插件**，故 `{{upstreams N}}` 模板需由本工具自行解释——解释规则见 ADR-016。
