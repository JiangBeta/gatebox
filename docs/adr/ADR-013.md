# ADR-013：证书管理——Caddy ACME + 抽象层

- 状态：已接受
- 日期：2026-08-21

## 背景

域名功能涉及证书签发。原 ADR-006 定「Caddy ACME 自动、代理即签证、无独立证书管理」。讨论中一度倾向独立证书管理（复用私钥 / 申请历史 / 下载证书 / 多颁发机构），最终为求简单维持 Caddy ACME，但要求保留升级为独立 ACME 客户端的框架。

## 决策

1. **证书执行者：维持 Caddy ACME**（ADR-006）——证书自动签发 / 续期、代理即签证，不引入独立 ACME 客户端。
2. **证书粒度：每二级域名一张证书**（Caddy 默认）；概览按 rootDomain **聚合**展示证书最坏状态（有已过期标红、有快过期标黄、全未申请标未申请、否则成功）。
3. **证书管理器抽象**：证书访问包一层「证书管理器」接口（当前实现走 Caddy Admin API 读状态），未来切换独立 acme 客户端时只替换实现、不改上层与页面。
4. **当前不提供**（留待独立 acme 时代）：手动重新申请、私钥复用 / 下载、申请历史、多颁发机构选择。

## 后果

- 优点：极简、证书全自动、无额外组件。
- 代价：「申请历史 / 私钥管理 / 多 CA」等能力暂缺，待引入独立 acme 时补回。
