# ADR-025：一级导航与命名 v2（6 入口 / Docker→容器 / 域名页 DDNS）

- 状态：已接受
- 日期：2026-09-07
- 前置：ADR-011（目录）、ADR-018（网关 Tab 结构）

## 背景

PRD v2 扩展产品能力（网络模块、首页导航、DDNS Tab），原 5 入口导航（仪表盘/网关/Docker/域名/设置）不再覆盖新功能；且「Docker」作为一级导航名与领域模型（容器）不一致。

## 决策

1. **一级导航扩为 6 入口**：**首页 / 网关 / 容器 / 域名 / 网络 / 设置**（`docs/layout.md` §2）。
   - 首页：导航（内嵌 flame）+ 仪表盘（原「仪表盘」并入并前置）。
   - 网络：内网 DNS（mosdns）+/ 组网（Tailscale），内容见 `docs/network.md`。
2. **「Docker」更名「容器」**：路由 `/docker` → `/containers`，标题、菜单、术语表、代码注释统一；领域对象仍用 ComposeInstance / Container / Service。
3. **域名页 Tab 调整为 4**：概览 / 域名 / 证书 / **DDNS**（原「DNS 凭证」Tab 并入「DDNS」Tab，acme + ddns 共用，见 ADR-024）。
4. **三十多处 UI/文档同步**：layout.md、router、App.vue 侧边栏、glossary、单位文档引用。

## 后果

- 优点：导航承载 v2 全部能力；术语与领域模型对齐；域名页 Tab 更贴近能力语义。
- 代价：路由更名需前端一次性迁移（hash 路由，历史链接失效可接受）；「容器」与「网关-容器图标」命名并存需在 glossary 锁定。
- 约束：命名同步点散点多，需在单位①一次改净（`docs/infra.md` §7）。
