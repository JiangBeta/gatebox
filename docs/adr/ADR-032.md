# ADR-032：前端分层与设计 token 强制

- 状态：已接受
- 日期：2026-09-14
- 前置：ADR-031（仓库目录 v3）
- 参考：Vue Admin 四层目录规范、antdv-pro、nunu-layout-admin（Vue3 + AntDesignVue）

## 背景

现有前端 9500 行：通用壳组件（`AppButton/AppModal/...`）零使用、`AppFormModal` 名为通用实为网关业务；变量页整页复制；CRUD 骨架重复 5+ 处；主题 token 传给了 `ConfigProvider` 但结构不匹配、从未生效；425 处内联样式、颜色字号硬编码；无状态层与 composable。用户诉求是「统一标准，不再讨论功能放哪层、字号多大」，而非「换一个 admin 框架」。

## 决策

### 1. 保留 AntD，建立四层前端

```
frontend/src/
├── design/      # tokens：颜色/字号/间距/圆角唯一来源
├── lib/         # 业务无关：http、ws、format、message
├── app/         # 骨架：main、router、layout、stores、composables、通用组件
├── modules/     # 业务域：gateway / containers / domain / network / plugins / system
│   └── <domain>/{api.ts, views/, components/}
└── shared/      # 跨模块类型/常量
```

- 布局与 CRUD 范式参照 `antdv-pro`；**不引入 Element Plus，不引入完整 admin 模板**。
- 移除死依赖：`naive-ui`、`@vicons/ionicons5`。

### 2. 判层规则与依赖方向

- 规则见 `docs/architecture.md` §9.2。
- 依赖 `modules → app → lib`，`shared` 单向；由 `eslint no-restricted-imports` 强制。
- 消除重复：CRUD 收敛为 composable（`useCrud`/`useAsync`/`useMessage`）；日志弹层、变量页等抽为领域模板。

### 3. 设计 token 强制

- `design/tokens` 为视觉值唯一来源；`.vue` 禁止样式字面量，由 `stylelint` 强制。
- **「字号大一点」= 改 token 或换档（`fontSize.sm/base/lg`），不再是逐页讨论项。**

### 4. 复用现有资产

`CodeEditor.vue`（CodeMirror 封装）保留并纳入 `app/components`；`ComposeEditorModal` 等业务组件迁入对应 `modules/<domain>/components`。

## 后果

- 优点：层级、样式、依赖方向均由工具强制，跨开发者协作不再依赖口头约定。
- 代价：需要一次性重建前端骨架并迁移三大页面（P3），引入 stylelint/eslint 配置。
