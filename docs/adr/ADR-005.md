# ADR-005：Docker 访问方式

- 状态：已接受
- 日期：2026-08-20

## 背景

「Docker 应用运维」需要完整的容器生命周期能力（list / start / stop / restart / stats / logs / events + compose 编排）。

## 决策

- **容器生命周期操作** → 走 **Docker Engine API**（Go SDK `github.com/docker/docker/client`，moby client）。
- **compose 编排**（`up -d` / `down`）→ 走 **`docker compose` CLI**（Compose 是 CLI 插件功能，无稳定 HTTP API）。

两者底层统一经 `docker.sock`（docker.sock 是传输层、Docker API 是协议层，非对立）。

控制深度为**完整生命周期**（读写 `docker.sock`，可启停/日志/代跑 compose up）。

## 后果

- 优点：结构化、可编程，stats/logs 流式友好。
- 风险：**可写 `docker.sock` 等价于宿主机 root 权限**，必须在 UI/文档显式告知。
