# ADR-001：控制面 + 独立外部组件

- 状态：已接受
- 日期：2026-08-20

## 背景

GateBox 需要反向代理、证书、DDNS、容器运维能力。可选「内嵌这些工具」或「作为独立组件管理」。

## 决策

采用**控制面 + 独立外部组件**架构：GateBox 本体是控制面；caddy、ddnsgo、docker、docker-compose 是 4 个独立外部组件。

- 可打包进本项目一起分发，但**进程独立、独立升级**，本项目不接管其生命周期。
- 本项目只通过「**改写它们的配置文件**」+「**调用它们的 API/CLI**」读写它们。

## 后果

- 优点：升级解耦（组件各自升级）、职责清晰、符合「极简」定位。
- 代价：需维护对每个组件的配置生成 / API 调用逻辑。
