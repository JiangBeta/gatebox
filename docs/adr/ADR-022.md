# ADR-022：运行时目录架构 v2（conf/ 集中 + Caddyfile 备份上提）

- 状态：已接受
- 日期：2026-09-07
- 前置：ADR-011（v1 布局）、ADR-002（Caddyfile 写盘）

## 背景

PRD v2 调整运行时目录布局：把配置类文件（BoltDB、密钥、基础配置）从「根目录 `db/` 平铺」收敛到 **`conf/` 集中**，并把 Caddyfile 配置源备份上提根目录，便于备份/迁移/排查与后续 install.sh 统一初始化。

## 决策

1. **`conf/` 集中配置**（取代 v1 的根目录 `db/`）：
   - `db/gatebox.db` → `conf/gatebox.db`；`db/secret.key` → `conf/secret.key`。
   - 新增 `conf/gatebox.conf`：行式 `key = value`，记录 `data_dir`、监听端口、各组件路径等；加载优先级 **env > conf > 默认**（`config.Load`）。
2. **Caddyfile 备份上提**：reloadCaddy 成功后写盘 `$DATA_DIR/Caddyfile`（取代 `tools/caddy/Caddyfile`）；`tools/caddy/` 仅保留 `caddy` 二进制、`user/*.caddy` 扩展与 `logs/`。
3. **一次性迁移**：启动时检测 v1 布局（`db/` 存在且 `conf/` 不存在）→ 复制 `db/*` 到 `conf/` + 写 `.migrated` 标记（不删原文件）；迁移失败退出不启动。
4. `tools/acme/certs/`、`tools/ddnsgo/.ddns_go_config.yaml`、`appData/` 布局不变。

## 后果

- 优点：配置集中、`conf/` 可作为「配置备份」整体打包；Caddyfile 备份在根目录一眼可见；gatebox.conf 让 install.sh 可声明式落参数。
- 代价：一次破坏性布局迁移（两段式复制 + 标记，不删原文件）；历史硬编码路径需常量化（store/config/caddy tls 等）。
- 约束：迁移幂等；旧 `db/` 目录确认后由 install 脚本清理。
