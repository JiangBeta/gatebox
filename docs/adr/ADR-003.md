# ADR-003：DNS 凭证统一管理

- 状态：已接受
- 日期：2026-08-20

## 背景

证书 DNS-01（caddy）与 DDNS 上报（ddnsgo）都需 DNS 提供商的 API key，且通常是同一家（cloudflare / dnspod.cn / aliyun）。

## 决策

**统一管理**：本工具存一份 DNS 提供商凭证（BoltDB 加密存储），分别下发到 caddy（`tls dns` 配置）和 ddnsgo（YAML）。

## 后果

- 优点：一次配置、双向下发，凭证只加密存一处，避免两处重复/不同步。
- 约束：需实现凭证的加密存储与双端下发逻辑。
