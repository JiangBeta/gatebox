# ADR-009：部署形态与交付

- 状态：已接受
- 日期：2026-08-20

## 背景

目标系统多样（debian / ubuntu / archlinux / armbian / nixos / openwrt），架构 x86 & arm。

## 决策

**裸机单二进制**（内嵌 Vue 静态资源）为最佳形态；若不可行则 fallback 到「裸机 + Docker 双交付」。

交付：**install 脚本 + 打包二进制（多架构 tarball）**，脚本按 `uname -m` 选二进制、按发行版装 systemd / openrc / procd 单元。

## 后果

- 优点：访问宿主机 docker.sock / caddy / ddnsgo 路径最短，贴合「极简」。
- 代价：安装脚本需处理多发行版的差异（init 系统、目录布局）。
