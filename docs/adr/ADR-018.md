# ADR-018：网关领域模型与页面结构

- 状态：已接受
- 日期：2026-08-31

## 背景

网关单位（开发计划第 3 项）是全新开发。PRD §6 定义了 `App ──< ProxyRoute` 两层模型，但落地前需与 Docker 单位已落地的 caddy label 派生机制（ADR-017 §2）对齐，并守住「GateBox 不接管 caddy 生命周期」原则。本轮 grilling（`/grill-with-docs`）就领域模型层次、页面结构、控制语义、类型范围、术语、Handler 概念作出决策。

## 决策

1. **数据模型 = 两层落库真相 + 派生视图**：保留 `App(1) ──< ProxyRoute(N)` 两层；**仅 `source = manual` 的 App 及其 ProxyRoute 落库**（BoltDB）；`source = docker` 整体是运行时派生视图，每次打开从 `GET /docker/proxyable` + 读 caddy label 生成，不建实体（对齐 ADR-017 §2）。UI「代理」列表按 **route 粒度**把「落库 route + 派生 docker route」合并为一张扁平表，一行 = 一条 route。

2. **页面 = 2 Tab**：`代理` + `Handlers`。取消 `layout.md` 原定的第三个 Tab「caddy 控制」——进程启停不做，「重新加载 Caddyfile（`/load`）」内嵌进「代理」页每次增删改自动触发；caddy 进程可见性（版本/运行时长/最近一次 `/load` 结果）降级为「设置 → 关于」的一块或顶部状态条。

3. **控制语义 = route 级**：「停止」= 禁用该 route（生成 Caddyfile 时排除其 site block + `/load`，实体保留、标「已停止」、可恢复启用）；「重启」= 对 `Docker 自动` 指重启后端容器（复用 Docker 单位能力），对反代/静态指重新加载该 route；**caddy 进程级启停本期不做**。

4. **类型收敛**：本期「类型」为三类——`反向代理`（reverse_proxy）/ `静态文件`（file_server）/ `Docker 自动`（source=docker 派生）。`tcp_stream`（L4 透传）后置；`host` 并入 `manual`（手动反代默认 `127.0.0.1`）；本期单上游（字段设计为数组以向后兼容，UI 先暴露单个）。

5. **术语**：弃用「router」，统一「后端（upstream）」（地址/端口）；「**代理类型**」（反向代理/静态文件/Docker 自动，决定流量去哪）与「**Handler**」（中间件，决定流量怎么处理）两分——caddy 中 reverse_proxy/file_server 本身也是 handler，不厘清会撞名。

6. **Handler = 修饰型中间件**：指 encode（Gzip/Br）、basic_auth、header、rewrite、redir 等「修饰型」指令，**不含** reverse_proxy/file_server 等「路由型」。采用「**内置清单 + 用户实例**」两层：内置清单硬编码（非用户数据），用户创建的是「handler 实例」（从清单选类型 + 填参数，落库）。「默认 Yes/No」= **全局默认集**：一批默认启用的 handler（如 encode）对所有 route 自动生效、不写进每条 route，route 级可覆盖。删除限制 = 被 route 显式引用时禁删（引用计数）。

## 后果

- 优点：docker 代理的派生视图与落库实体在同一张扁平表统一呈现，但底层不重复存储、无一致性负担；「不接管 caddy 生命周期」原则得到贯彻；类型收敛让 MVP 的 Caddyfile 生成器只需覆盖 reverse_proxy / file_server 两条路径。
- 代价：docker 派生 route 的增删改受限于「改写 label / 编排」而非网关本地，需跳转 Docker 单位；route 级「重启」对反代/静态只是重载、语义偏弱。
- 约束：Caddyfile 生成器必须支持「排除某 site block」（停用）而不影响其余；Handler 引用计数需在删除/编辑路径上维护。

## 修订 2026-09-01：网关 UI 与功能重设计（supersede 下述决策）

> 本轮 `/grill-with-docs` 对网关 UI/功能重设计定案。以下条目**覆盖**本文档对应原决策与 ADR-019/020/021 的冲突点。术语「ProxyRoute/route」在网关语境下改称「服务（Service）」。

### 覆盖点

1. **模型升级为三层 `App(1) ──< Service(N)`，Service 内联 0..N 域名行**：
   - **App（应用）**：落库分组实体 `id/name/description/createdAt`，**不与 rootDomain 绑定**（明确推翻原「host 并入 manual、App 仅占位」的表述；ADR-019 的 App 表现在**正式建立**，`appId` 为真外键）。
   - **Service（服务）**：即原 ProxyRoute，`id/appId/name/description/type/domains[]/upstream[]/root/healthUri/handlerIds[]/enabled/createdAt`。`host`(单串) 升级为 **`domains[]`**：`{protocol(https/http), subdomain, rootDomain, customPort{custom,port}}`。同一 Service 的多个域名行 = 指向同一后端（upstream/root）的多个别名，共享同一 `代理类型`。
   - **代理规则（route）** 一词在「创建代理」指**整棵应用**批量创建（应用 + 其下全部服务）。

2. **页面「创建代理」合并**：原「创建反代」+「创建静态文件」两按钮合并为单个「+ 创建代理」；代理类型（反向代理/静态文件）改为服务内的 `Z-B` 单选，见 gateway.md §3 终案图。

3. **协议范围**：域名行支持 https/http；**本修订沿用 ADR-021「一律 HTTPS 为主」但放开 http/自定义端口**（http/非 443 = 无证书内网代理，明确推翻 ADR-021 的「一律 HTTPS」）。**L4（tcp/udp）确认本期后置**（caddy v2.11.4 标准版无 caddy-l4 插件，QD 已核实），见 gateway.md §8。

4. **Handler → Caddy 片段**：沿用「内置清单 + 用户实例」，但实例改为**通用 JSON 片段**：
   - 片段遵循 **caddy 自身 JSON 规范**（语法可直接用），仅变量位用 GateBox 语义，如 `<%GB_STATIC_ROOT%>/<%GB_SERVICE%>`（推翻 ADR-020「每 handler 硬编码渲染函数」为「通用片段 + 生成器模板插值」）。
   - 片段带 `标签 ∈ {handler, route}`（handler=site block 中间件；route=route 级如健康检查/日志），仅 UI 区分。
   - 默认自带条目 **8 个只读硬编码**（Gzip/Br、Basic Auth、忽略自带证书校验、健康检查、日志配置、阻止常见漏洞、静态资源缓存、支持 websocket）；Q7 定**不落库为可编辑实例**（推翻 ADR-020 「`default` 进全局默认集」）。

5. **全局默认集 → 每路由预勾选**：推翻原「`default` 全局 snippet `(gatebox-default)`」方案（ADR-019/020）。新语义（Q8）：
   - 片段有「默认启用」（默认关）：开则在该 service 的「其他选项」里**默认勾选**；
   - 片段有「默认隐藏」（默认关）：开则在「其他选项」中**不显示**（但仍随默认勾选生效）。
   - 每个 Service 落库自己的 `handlerIds[]`（route 级覆盖）；「其他选项」=「禁用当前规则 (= enabled)」+ 3 安全开关 + 所有非隐藏片段 toggle。

6. **列表按应用分组**：代理列表按 App 折叠分组（折叠头=应用名+描述），行=Service；「Docker 自动」派生 service 放固定只读分组（不属任何 App）。删除应用 = 级联删其下服务（沿用「服务须已停用」约束）。

7. **GateBox 变量系统**（2026-09-01，Q2 follow-up）：
   - 定界符统一 **`<% … %>`**，与 caddy 运行时环境变量 `${ENV}`（原样透传、不替换）**彻底区分**（推翻点 4 示例里用裸 `${…}` 的写法）。
   - **内建只读闭集 4 个**：`<%GB_APP%>`、`<%GB_SERVICE%>`、`<%GB_STATIC_ROOT%>`、`<%GB_HOST_PORT%>`（不可删改）。
   - **用户自定义变量**：CRUD 界面新增/改/删/查；key 不得以 `GB_` 开头（保留前缀）；值任意字符串。
   - 解析时机：生成器渲染 site block 按「内建（App/Service 上下文）→ 用户全局查表」替换；未命中 `<% … %>` 报配置错误。
   - 片段编辑器提供「变量」button，点击在光标处插入 `<%VAR%>`。
