# ADR-021：网关收口决策（访问协议 / 删除联动 / 默认集）

- 状态：已接受
- 日期：2026-08-31

## 背景

`docs/gateway.md` 定稿前，就访问协议、删除 route 的 DNS 联动、全局默认集语义三个收口点作出决策。

## 决策

1. **访问协议 = 一律 HTTPS**：反代/静态 route 全部走 443（caddy 自动签证书 + 80→443 redirect），`port` 列纯展示。纯 HTTP 内网代理（不签证书）后置。

2. **删除 route 的 DNS 联动**：删除反代/静态 route 时**同步清除 ddnsgo 里该二级域名的上报记录**（重写 ddnsgo YAML + 重启），保持「代理」与「DNS 上报」一致；caddy 证书随 site block 移除自动失效，由 caddy 托管、无需额外处理。

3. **全局默认集语义**：**多个 handler 实例可同时 `default=Yes`**，进全局默认集后叠加进 snippet（如 encode + 一个全局 header 同时默认生效）。

## 后果

- 优点：协议单一、Caddyfile 生成器无需处理 HTTP/HTTPS 分支；DNS 记录与代理同生命周期，不留无主记录。
- 代价：纯 HTTP 内网场景本期不可用；删除 route 多一次 ddnsgo 重写/重启。
- 约束：删除 route 需在 ddnsgo 可用时完成联动，ddnsgo 不可达需给出可重试/降级提示。
