#Docker--创建应用的前端界面及功能说明
## 0.1 控件标注说明
  - I 为input框
  - K 为开关按钮
  - S 为select框
  - T 为多行文本输入框
  - Z 组合，如：
    - Z-B 为单选button组合
    - Z-IS 为input+select组合框
    - Z-IB 为input+botton组合框
    - Z-BS 为单选按钮+select
    - Z-BIS 为 单选buttun+input+select组合
## 0.2 默认容器名称说明
  - service_name（容器名称）：form的应用名称，yaml的container_name
  - hostname（容器的主机名称）：<service_name>.gatebox.local

## 2. Form 区域
┌────────────────────────────────────────────────────────┐
│ 基本信息：                                             │
│ [应用名称 ]          [镜像]                            │
│ [创建后状态]         [重启策略]       [关联宿主机 PID] │
│ ┌──────────┐                                           │
│ │ 基本配置 │ 运行配置   关联配置                       │
├─┘          └───────────────────────────────────────────┤
│ 环境变量             [+ 添加变量]                      │
│ [变量名]  [变量值]  [- 删除]                           │
│ ------------------------------------------------------ │
│ 挂载或存储卷         [+ 添加目录]                      │
│ [宿主目录/存储卷]   [容器内部路径]  [- 删除]           │
│ ------------------------------------------------------ │
│ 端口映射             [+ 添加端口]                      │
│ [外部访问端口]  [容器内部端口]  [- 删除]               │
│ ------------------------------------------------------ │
│ 域名访问             [+ 添加域名访问]                  │
│ [外部访问端口]  [容器内部端口]  [- 删除]               │
├────────────────────────────────────────────────────────┤
│                      [校验] [保存] [保存并部署] [关闭] │
└────────────────────────────────────────────────────────┘

  - 基本信息
    - 应用名称（I）：必填
    - 镜像（Z-IB）：必填
      - input框（I）：不可输入，只显示提示或选择好的镜像
      - 选择镜像（ZB）
        - 选择镜像（B）：默认，点击后弹出已有镜像列表，用于单选
        - 拉取镜像（B）：点击弹出拉取镜像层，功能复用“镜像--拉取镜像”
    - 创建后状态（ZB）：必填
      - 启动容器（B）：默认，点击即选择
      - 仅创建容器（B）：点击即选择
    - 重启策略（S）：必填
      - 选项：一直重启（默认）｜非手动停止则重启｜失败后重启｜不重启
    - 关联宿主机 PID（K）
      - 默认关闭

  - 基本配置
    - 环境变量
      - 添加变量（B）：点击后增加一组环境变量
      - 环境变量（一组）：
        - 变量名（I）：提示 “变量名，Key”
        - 变量值（I）：提示 “变量值，Value”
        - 删除（B）：点击删除这一组变量，使用icon表示，点击后有确认框 
    - 挂载或存储卷
      - 添加目录（B）：点击后增加一组映射目录
      - 映射目录（一组）：
        - 宿主目录/存储卷（Z-BIS）：
          - 宿主机文件目录（Z-B）：默认路径（默认）/自定义路径/存储卷
          - 路径/卷名（I）：
            - 默认路径：提示 “只需填写文件或文件夹名，如“logs”、“data””
            - 自定义路径：提示 “需填写绝对路径，如“/var/run/docker.sock””
            - 存储卷：提示 “输入存储卷名称”（关联存储卷，可以点击选择，输入没有的存储卷则自动新建）
          - 权限（S）：读写（默认）/只读
        - 容器内部路径（I）：提示 “容器内路径”
        - 删除（B）：点击删除这一组映射，使用icon表示，点击后有确认框
    - 端口映射
      - 添加端口（B）：点击后增加一组端口映射
      - 端口映射（一组）：
        - 外部访问端口（Z-IS）：
          - 端口号（I）：提示“外部访问端口，留空使用随机端口”
          - 协议（S）：tcp（默认）/udp/tcp & udp
        - 容器内部端口（I）：提示 “容器内程序运行的端口”
        - 删除（B）：点击删除这一组映射，使用icon表示，点击后有确认框
    - 域名访问
      - 添加域名访问（B）：点击后增加一组域名访问
      - 域名访问（一组）：
        - 子域名（I）：提示 “只填写子域名，如“caddy”、“ddnsgo””
        - 根域名（S）：关联“域名--域名管理”中的域名，可走此新建
        - 指向端口（S）：关联“端口映射”中的外部端口
        - 访问端口（Z-BI）：
          - 端口选择（Z-B）：WEB（默认）/其他
          - 端口号（I）：
            - WEB：不可输入，显示“80”或“443” （关联“域名”，该域名有凭证则443，无凭证则80）
            - 其他：提示“请输入端口号”
        - 密码访问（Z-B）：无需密码（默认）/启用简单密码（Caddy basic_auth功能，后续在“网关”部分实现）     
        - 删除（B）：点击删除这一组域名访问，使用icon表示，点击后有确认框

  - 运行配置
    - 日志配置
      - 日志格式（S）：Json-file(默认)/Journal  （docker 中 --log-driver string）
      - 单文件大小，单位MiB（I）：提示 “填写数值，不填默认“2”MiB”
      - 最大日志保留数（I）：提示 “超出自动清理，不填默认“5”个”
    - 健康检查
      - 重复间隔（I）：提示“单位秒，不填默认30”
      - 超时判断（I）：提示“单位秒，不填默认10”
      - 失败重试次数（I）：提示“填写数值，不填默认“3”次”
      - 脚本执行环境（S）：CMD 直接调用命令（默认）/ CMD-SHELL 通过 Shell 执行
      - 执行脚本（T）：提示“配置健康检查脚本，不填写默认“curl -f http://localhost:<获取第一组端口映射的内部端口>/ || exit 1””
    - 资源限制
      - 共享内存大小，单位MiB（I）：提示“填写数值，默认“64”MiB”  （Docker 中--shm-size）
      - 最大 CPU 配额（Z-B）：不限制（默认）/1核/2核/3核 (--cpus decimal，显示实际检测到的CPU数量)
      - 最大内存配额（Z-BIS）：（--memory bytes）
        - 内存配额（Z-B）：不限制（默认）/限制大小
        - 内存大小（I）：选限制大小才能输入，提示“输入最大内存数值”
        - 单位（S）：GB（默认）/MiB
      - GPU 能力
        - 使用 GPU （K）：默认关闭，以下选开才显示
          - 设备列表（I）：提示“指定设备UUID或ID，不填则使用所有设备”
          - 计算能力（S）：（--gpus 'capabilities=compute,utility'），多选
            - “compute - 计算能力”/“compat32 - 兼容32位”/“graphics - 图形处理能力”/“utility - 监控管理能力”/“video - 视频处理能力”/“display - 图形显示能力”

  - 关联配置
    - 启动依赖 depends_on （S）：可选择已启动的容器或本Compose在编辑的容器
    - 关联网络 : 
      - 创建网络（B）：功能同Docker-网络-创建网络
      - 加入现有网络（B）：点击后显示现有网络列表（名称、类型、IPV4、操作），点击某一网络的加入按钮（icon）后，显示一组网络配置
      - 网络配置（一组）：
        - 网络名称（I）：显示网络名称，不可操作
        - 容器别名（I）：提示“指定本容器别名”（不能是service_name与hostname）
        - IPV4 地址（I）：提示“输入本容器地址”（右侧显示本网络的地址段，如“172.19.0.0/16”用于参考）
        - 删除（B）：点击删除这一组网络配置，使用icon表示，点击后有确认框
    - 关联宿主机网络（将宿主机及其内网主机关联到容器的hosts）
      - 添加宿主机网络（B）：点击后添加一组host
      - 宿主机网络host（一组）：
        - Hostname（I）：提示“输入 Hostname”
        - IP（I）：提示“输入 IP 地址”
        - 删除（B）：点击删除这一组host，使用icon表示，点击后有确认框
    - 关联设备
      - 添加关联设备（B）：点击后添加一组设备关联
      - 设备关联（一组）：
        - 宿主机路径（I）：提示“设备路径，如“/dev/tty0””
        - 容器内路径（I）：提示“如“/dev/tty0””
        - 删除（B）：点击删除这一组设备，使用icon表示，点击后有确认框

## 3. YAML 区域
  - 选型：codemirror-editor-vue3
  - 编辑功能：
    - 查找 & 替换
    - Theme 选择
    - 字体大小选择
  - 其他要求：
    - 显示缩进，启用缩进辅助线对齐，设置2个空格缩进（同时tab也为2个空格），当粘贴过来的tab制表符不是空格时，请与空格区分（最好能转换）；
    - 功能要求：
      - yaml 语法，包括高亮、缩进等
      - docker-compose 补全
      - Schema 格式检查
    - 使用maple-mono字体显示：npm按需精准引入（不要全量包）
    - 复制按钮：一键复制Compose代码
